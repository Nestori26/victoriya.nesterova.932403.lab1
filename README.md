# Лабораторная работа №1

## Создание сайта «О себе» как о языковом энтузиасте и переводчике

### Реализация

В HTML-документе были использованы:

- `<header>` — шапка страницы;
- `<main>` — основная часть;
- `<section>` — секции «Навыки» и «Проекты», представленные в виде списков;
- `<aside>` — боковая панель;
- `<footer>` — подвал с копирайтом и годом;
- изображение с атрибутами `src`, `alt`, `width`, `height`;
- форма с полями «Имя», «Email», «Сообщение» и кнопкой «Отправить».

Сайт выполнен в бирюзово-белой цветовой гамме.

### Технологии, использованные в работе

- HTML5
- CSS3
