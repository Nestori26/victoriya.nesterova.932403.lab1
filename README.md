# Лабораторная работа №6

## Введение в Node.js и базовый сервер на Express

### Реализация

В скрипте реализовано:

- **Node.js:** Инициализация Node.js-проекта и управление зависимостями..
- **HTTP-сервер на Express:** отдаёт статические файлы (HTML, CSS, JS, иконки).
Три маршрута:
GET / — главная страница (интерфейс генератора).
GET /about — страница «О себе»/о проекте.
GET /api/uuid — API-эндпоинт, возвращающий JSON.
- **Обработка query-парметра** приведение строки к числу и проверка на целочисленность.
- **Валидация входных данных:**
  - Числа от 1 до 10;
  - Если выйти за диапазон возвращается 400 Bad Request;
- **Генерация UUID**
- **Manifest.json** c обязательными полями.
- **Serviceworker** кеширование статических ресурсов на событии install, перехват запросов на событии fetch, отдача статики из кеша, обеспечение работы страниц в офлайн режиме .
- **Serviceworker регистрация на странице**
