# Лабораторная работа №4

## Основы JavaScript: подсчёт прогресса изучения языка

### Реализация

В работе добавлен внешний скрипт `script.js`, подключённый к странице через тег `<script>`.
Скрипт реализует обработку массива с количеством новых слов, выученных за день, и выводит статистику прогресса.

В скрипте реализовано:

- **Ввод данных:** `prompt` для получения имени пользователя.
- **Вывод данных:** `alert` для приветствия и итоговой статистики, `console.log` для подробных данных.
- **Условные конструкции:** проверка введённого имени, проверка среднего значения слов.
- **Циклы:** перебор массива для поиска максимума и подсчёта дней с малым прогрессом.
- **Функции для работы с массивами:**
  - `findMax(arr)` — поиск максимального значения (лучший день);
  - `filterHighProgress(arr)` — фильтрация дней с высоким прогрессом (> 50 слов);
  - `sumArray(arr)` — подсчёт общей суммы выученных слов.
- **Дополнительная логика :** если среднее количество слов в день больше 30, в консоль выводится сообщение об отличном темпе.
