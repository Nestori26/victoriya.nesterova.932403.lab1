# Лабораторная работа №2

## Оформление страницы «О себе» с помощью внешнего CSS-файла

### Реализация

Основной стиль вынесен во внешний файл `style.css` и подключён к странице через тег `<link>`.
Во внутреннем блоке `<style>` во `<head>` задано правило для выравнивания списка навыков.
Inline-стиль `flex-direction: column` применён к форме обратной связи.

В работе реализовано:

- CSS-переменные в `:root` для цветов и шрифтов;
- переключатель языковой темы, сделанный из `<span>`;
- три темы — «Русский», «English», «中文» — с разными цветами;
- смена темы через JavaScript: скрипт добавляет класс `theme-ru`, `theme-en` или `theme-cn` к тегу `<html>`;
- цветные рамки при `:focus` на полях ввода в зависимости от языка поля;
- примеры позиционирования: `static`, `relative`, `absolute`;
- состояния элементов: `:hover`, `:active`, `:focus`, `:visited`;
- контрастность текста не менее 4.5:1 по стандарту WCAG AA.

### Переменные в :root

- `--color-primary` — основной бирюзовый цвет текста;
- `--color-accent` — бирюзовый акцент для фонов;
- `--color-white` — белый (акцент);
- `--color-light` — светло-бирюзовый;
- `--color-bg` — фон страницы;
- `--font-base` — базовый шрифт;
- `--font-heading` — шрифт для заголовков;
- `--space`, `--radius`, `--transition` — отступы, скругления и анимации.

### Темы

- **theme-ru** — бирюзово-белая цветовая гамма;
- **theme-en** — синий и красный (флаг Великобритании);
- **theme-cn** — красный и жёлтый (флаг Китая).

### Позиционирование

- `static` — у блока `.static-note` в боковой панели;
- `relative` — у тега `<header>`, `<aside>` и обёртки `.avatar-wrap`;
- `absolute` — у бейджа `.badge`, который прижат к верхнему правому углу аватара.

### Состояния элементов

- `:hover` — у переключателя темы и ссылки в подвале;
- `:active` — у переключателя темы, ссылки и кнопки «Отправить»;
- `:focus` — у полей ввода (цветная рамка в зависимости от языка);
- `:visited` — у ссылки в подвале.

### Технологии, использованные в работе

- HTML5
- CSS3
- JavaScript (переключение темы)
