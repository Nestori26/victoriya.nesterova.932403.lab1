# Лабораторная работа №3

## Flexbox, CSS Grid и адаптивная вёрстка страницы «О себе»

### Реализация

В работе дополнен макет страницы из ЛР №2 с помощью Flexbox и CSS Grid.
Реализованы:

- **Flexbox-навигация** в шапке — горизонтальное меню из 5 пунктов, адаптируется под ширину экрана;
- **Flex-карточки «Изучаемые языки»** — 3 карточки с флагом, названием и уровнем владения;
- **Grid-галерея «Фраза недели»** — 3 блока с фразой, переводом, транскрипцией и аудио-иконкой;
- **Медиа-запросы** для планшетов (до 900px) и мобильных (до 600px);
- **Адаптивность**: карточки — 1/2/3, Grid — 1/2/3 в зависимости от ширины экрана;
- **Отсутствие горизонтальной прокрутки** при любом размере окна;
- **Контрастность текста** не менее 4.5:1 по стандарту WCAG AA;
- **Атрибут `lang`** для карточек и фраз на разных языках.
### Технологии, использованные в работе
- HTML5
- CSS3 (Flexbox, Grid, медиа-запросы)
- JavaScript (переключение темы)
