# Лабораторная работа №5

## DOM и взаимодействие с элементами страницы (Словарь переводчика)

### Реализация

В работе создан интерактивный интерфейс для управления личным словарём переводчика (Вариант 17). Все действия выполняются динамически, без перезагрузки страницы. Состояние словаря и выбранная тема сохраняются в `localStorage`.
В работе реализовано:
- **Поиск элементов (3 способа):** использование `getElementById` (для кнопок и `tbody`), `querySelector` (для поиска секции `#dictionary` и таблицы), `querySelectorAll` (для массового удаления строк и сбора данных).
- **Обработка ошибок:** функция `checkElements()` проверяет наличие всех критичных элементов при запуске. Если элемент не найден — выводится ошибка в консоль, и инициализация прерывается.
- **Манипуляции с DOM:** создание строк `<tr>` через `document.createElement`, заполнение ячеек `<td>`, создание кнопок удаления и добавление в таблицу через `appendChild`.
- **Удаление элементов:** удаление конкретной строки через `remove()` с предварительной CSS-анимацией исчезновения (класс `row-removed`).
- **Переключение темы:** кнопка меняет класс `theme-light` / `theme-dark` у `<body>`, обновляя CSS-переменные.
- **Скрытие/показ:** кнопка «Свернуть словарь» скрывает таблицу (добавляет класс `hidden`), а текст кнопки меняется на «Развернуть словарь».
- **Сохранение состояния (`localStorage`):** данные сохраняются в виде JSON-строк. При удалении строки словарь пересобирается из текущего DOM (`rebuildDictionaryStorage`). При перезагрузке страницы тема и словарь восстанавливаются.
### Логика работы 
- **Добавить слово:** через `prompt` запрашивается слово и его перевод. Создаётся строка, которая добавляется в таблицу и сохраняется в `localStorage`. Если ввод отменён — выводится сообщение в консоль.
- **Очистить словарь:** удаляются все строки из `tbody`. Если словарь уже пуст — выводится `alert` «Словарь уже пуст». Перед удалением запрашивается подтверждение через `confirm`.
- **Удалить слово:** у каждой строки есть кнопка «Удалить», которая запускает анимацию и удаляет именно эту строку, обновляя хранилище.
- **Свернуть словарь:** скрывает таблицу и меняет текст на кнопке.
### Технологии, использованные в работе
- **HTML5** — семантическая разметка таблицы и кнопок.
- **CSS3** — стилизация, CSS-переменные для тем, анимация исчезновения строк (`row-removed`).
- **JavaScript (ES6+)** — логика работы приложения.
- **DOM API** — `getElementById`, `querySelector`, `querySelectorAll`, `createElement`, `appendChild`, `remove`, `classList`, `textContent`, `setAttribute`.
- **Web Storage API** — `localStorage` для сохранения словаря и темы, `JSON.stringify` / `JSON.parse`, обработка исключений через `try...catch`.
- **События DOM** — `addEventListener`, `DOMContentLoaded`.
